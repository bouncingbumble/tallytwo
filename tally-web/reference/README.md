# The prototype engine as a Node module

`proto-oracle.cjs` is the engine/AI `<script>` of `../../tally-two-handoff/reference/tally-two-saloon.html` with the DOM cut away, generated by `make-oracle.cjs`. `npm run verify:port` replays games through it and through `src/` move for move; it is vendored here so a bare clone of this folder can run the check.
